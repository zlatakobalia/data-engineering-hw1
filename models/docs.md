# Аналитический слой интернет-магазина в Greenplum

Первый слой сквозного проекта курса Data Engineering. Сырые таблицы OLTP-базы магазина (PostgreSQL)
сервис `loader` копирует как есть в Greenplum — база `dwh`, схема `raw`. dbt превращает их в витрины
по схеме «звезда». Дальше сборку будет запускать Airflow, а рядом появятся потоковые данные из Kafka и ClickHouse.

## Слои

| Слой | Схема | Материализация | Что делает |
|---|---|---|---|
| staging | `analytics_staging` | view | По одной модели на таблицу источника `stg_shop__*`: переименование, типы, простые флаги. Только здесь `source()` |
| intermediate | `analytics_intermediate` | view | JOIN, агрегации, рекурсивное дерево категорий |
| marts | `analytics_marts` | table / incremental | Факты `fct_*` и измерения `dim_*` — то, что читают отчёты |

## Звезда

- **fct_orders** — один заказ; **fct_order_items** — один товар в заказе.
- **dim_customers** — клиент, включая не купивших; **dim_products** — товар с иерархией категорий;
  **dim_dates** — календарь.

Главное бизнес-понятие — **подтверждённая покупка** (`is_confirmed`): заказ в статусе `paid`,
не тестовый, с хотя бы одной успешной оплатой; возврат оплатой не считается. Полное определение —
в описании колонки `is_confirmed` любой из витрин.

## Примеры вопросов

- выручка по месяцам и категориям: `fct_order_items` × `dim_dates` × `dim_products`, `where is_confirmed`;
- доля покупателей по каналам привлечения: `dim_customers` (`is_buyer`, `acquisition_channel`);
- средний чек по городам: `fct_orders` × `dim_customers`, `avg(order_amount)` по подтверждённым;
- какие бренды чаще возвращают: `fct_order_items` × `dim_products`, доля позиций со статусом `returned`.

**Подтверждённая покупка** — заказ, который одновременно:

1. не тестовый и находится в статусе `paid`;
2. имеет хотя бы одну успешную оплату (`payment_status = 'success'`) с положительной суммой.

Возврат (успешная операция с отрицательной суммой) оплатой не считается. Поэтому заказ `paid`
без успешной оплаты (например, 119) — не подтверждённая покупка, а возвращённый заказ (`returned`) —
тоже нет, даже если его когда-то оплатили. Выручка магазина считается только по подтверждённым покупкам.
